OpenConnect — Product Features

Version 1.0.1 | Comprehensive Enterprise Payment Platform

Executive Summary​

OpenConnect is a unified, enterprise-grade payment platform that consolidates multiple payment networks, channels, and transaction types into a single, easy-to-integrate solution. With support for 50+ endpoints, real-time processing, guaranteed delivery, and comprehensive management capabilities, OpenConnect enables financial institutions to launch, scale, and operate modern payment services reliably and compliantly.

Core Logic & Routing​

OpenConnect Core Engine​

OpenConnect's core engine acts as a centralized transaction routing and switching engine for the entire payment ecosystem.

Routing & Switching​

What it does: OpenConnect intelligently routes all incoming payment requests to the appropriate payment network based on transaction type, beneficiary location, amount, and business rules.

Key Features:

Intelligent Message Routing

  • Analyzes incoming requests to identify type, source, and business intent
  • Tags messages to specific processing queues based on routing rules
  • Applies listener services that perform message transformation and business logic
  • Routes requests to the correct target system (RAAST, 1LINK, RTGS, etc.)

Configurable Routing Rules

  • Route based on message type (P2P, P2M, Bill Payment, Bulk, RTGS, etc.)
  • Route based on channel (Mobile App, Web, ATM, etc.)
  • Route based on transaction code and priority
  • Support for business rule-based dynamic routing
  • Failover Routing – Automatic alternate paths if primary system fails

Zero Transaction Loss Guarantee

  • Store & Forward (SAF) ensures no transaction is ever lost
  • Automatic retry mechanisms with configurable retry logic
  • Guaranteed delivery even during network failures or system outages
  • Complete audit and transaction logging with correlation IDs for full traceability

Benefits:

  • Loose coupling between systems
  • High scalability and throughput
  • Controlled, auditable transaction processing
  • Complete visibility and compliance

Benefits:

  • Support for cross-border and domestic payments
  • Regulatory compliance and future readiness

Queue Management​

Queue Engine (RabbitMQ)​

OpenConnect uses RabbitMQ as its core messaging backbone, ensuring reliable, asynchronous transaction processing at scale.

Queue Handling​

What it does:

  • Places each transaction into a specific queue based on business context
  • Enables asynchronous, non-blocking transaction processing
  • Provides fault tolerance and high availability
  • Allows parallel processing of multiple transactions

Benefits:

  • Asynchronous processing reduces latency
  • Fault-tolerant message delivery
  • High availability and redundancy
  • Support for millions of transactions per day

Routing via Queues​

What it does:

  • Controls transaction flow dynamically
  • Manages concurrency and processing load
  • Isolates processing logic for different transaction types
  • Enables horizontal scalability

Configuration Options:

  • Route based on transaction type (P2P, P2M, Bill, RTGS, etc.)
  • Route based on priority (Standard, High, Critical)
  • Route based on destination system
  • Dynamic queue allocation based on system load

Benefits:

  • Optimized performance
  • Flexible load balancing
  • Scalability to handle traffic spikes
  • Improved transaction processing speed

System Configuration​

OpenConnect provides granular, real-time configuration management for all integrations, APIs, and interfaces.

Interface Configuration​

Interface Setup​

What it does: Centralizes configuration of all external systems (banks, payment networks, gateways) in the ws_config table.

Configuration Parameters:

  • Protocol type (REST, SOAP, TCP, SFTP)
  • Host/IP address and port
  • Authentication type and credentials
  • Timeout and retry settings
  • SSL/TLS certificate management
  • Connection pooling settings

Benefits:

  • Centralized configuration management
  • No code changes required for system updates
  • Real-time configuration deployment

Message Configuration​

API Configuration​

  • Endpoint URLs and HTTP methods
  • Custom headers and authentication mechanisms
  • Request/response format specifications
  • Dynamic configuration loading at runtime

TCP Message Configuration​

  • ISO and TCP message structure definitions
  • MTI (Message Type Indicator) definitions
  • Data element mappings (position, length, data type)
  • Support for variable-length messages

Request–Response Mapping​

  • Input request transformation rules
  • Response parsing and mapping
  • Business rule application
  • Error handling and fallback logic

Token Configuration​

  • Secure token generation and management
  • Token caching and reuse
  • External authentication service integration
  • Automatic token refresh

Response Code Mapping​

  • External system response codes → Internal standardized codes
  • Ensures consistent behavior across integrations
  • Simplifies error handling
  • Improves user experience with standardized messages

Integration Support​

OpenConnect supports all major payment networks and integration types, enabling connections to any financial system globally.

Integration Types​

Web Services (SOAP & REST)​

  • Enterprise service integration (1LINK BPS)
  • Financial institution connectivity
  • Third-party payment gateway integration
  • RESTful and SOAP API support

TCP/IP Protocol​

  • Fixed-length and delimited message support
  • Core banking system integration (Temenos T24, Finacle, etc.)
  • Legacy system support
  • High-performance direct connections

ISO Standards​

ISO 8583 – For card payments and ATM transactions

  • Widely supported by banking systems
  • Legacy system standard
  • Still used for VISA, Mastercard, UPI schemes

ISO 20022 – For modern payment processing

  • Supported by RAAST, RTGS, CBPR+
  • Future-proof standard
  • Richer data capabilities

Key Integrations:

  • Instant Payments: RAAST (Pakistan), EthSwitch (Ethiopia), Aani (UAE)
  • Interbank Transfers: 1LINK IBFT, PayPak for cards, VISA, Mastercard, UPI
  • Core Banking: Temenos T24, Finacle, other CBS platforms
  • International: SWIFT MT/MX messaging

APIs (REST & SOAP)​

  • Bank APIs
  • NADRA APIs (national identity)
  • AML (Anti-Money Laundering) systems
  • SMS gateways
  • Fintech platforms

File-Based Integration​

  • CSV, Excel, TXT file processing
  • Batch settlement files
  • Reconciliation file exchange
  • Scheduled file transfers via SFTP

Communication Modes​

OpenConnect supports three communication paradigms for maximum flexibility:

Push (Synchronous)​

  • OpenConnect sends requests and waits for immediate responses
  • Best for: Real-time transactions requiring immediate confirmation
  • Example: P2P transfers, bill payments

Pull (Asynchronous)​

  • OpenConnect polls external systems for transaction status
  • Best for: High-volume transactions, batch processing
  • Example: RAAST and RTGS status inquiries
  • How it works: OpenConnect posts transaction via post-mx API, then polls status via get-mx API

File Exchange​

  • Scheduled or event-driven file transfers
  • Best for: Clearing, settlement, reconciliation
  • Supports SFTP, S3, local file systems

Transaction Processing​

OpenConnect handles all transaction types with specialized processing logic:

Instant Payments​

Real-Time Processing with Central Bank Compliance

  • Supports real-time transaction processing
  • Configurable business logic for incoming and outgoing transactions
  • Full Compliance: RAAST (Pakistan), Aani (UAE), EthSwitch (Ethiopia)
  • Each system has its own central bank mandates implemented
  • OpenConnect implements and maintains compliance with all requirements

Benefit: One platform, multiple instant payment systems, always compliant

RTGS (Real-Time Gross Settlement)​

High-Value Interbank Transactions

  • End-to-end RTGS transaction handling
  • Supports multiple input formats (APIs, MT format files)
  • Automatic conversion to MX format for PRISM+ (Pakistan's RTGS system)
  • Single-customer, multiple-customer, and FI-to-FI transactions

Benefit: Seamless RTGS processing with format conversion

Advice-Based Payments​

Guaranteed Delivery with Store & Forward

  • Advice transactions marked at OpenConnect level
  • Automatically stored in SAF queue
  • Processed with multiple retries at configured intervals
  • Guaranteed delivery regardless of system failures

Benefit: Zero transaction loss, guaranteed payment delivery

Aggregator Payments (Bill Payments)​

  • Utility bill payments (electricity, water, gas)
  • Government payments (taxes, fees)
  • Telecom payments (prepaid, postpaid, bundles)
  • Merchant invoice payments
  • Built-in inquiry and settlement handling

Benefit: Unified bill payment across all vendors and aggregators

Unified API Layer​

OpenConnect exposes comprehensive APIs for financial and operational functions:

Financial APIs​

Payment & Transfer Operations​

  1. 1LINK IBFT – Interbank fund transfers
  2. RAAST P2P – Peer-to-peer instant transfers
  3. RAAST P2M – Merchant payments (Static QR, Dynamic QR, Alias-based, RTP)
  4. RAAST Remittance – Remittance payments
  5. RTGS Transactions – Single/multiple customer transfers, FI-to-FI transactions
  6. Bill Payments – Utilities, government, aggregator payments
  7. Telco Transactions – Prepaid, postpaid, bundles
  8. SWIFT Transactions – International payment messaging
  9. Home Remittance – Overseas fund transfers
  10. Return Payments – Payment reversal and returns

Non-Financial APIs (Operational)​

Inquiry & Validation Functions​

  1. Unified Title Fetch – Multi-rail account validation with fallback
  2. Bill Inquiry – Fetch bill details before payment
  3. Transaction Inquiry – Check transaction status and history
  4. RAAST ID Management – Register, link, and manage aliases
  5. RTP Generation – Create Request-to-Pay workflows
  6. Request for Return – Initiate return payment requests
  7. Balance Inquiry – Check account balances
  8. Merchant Alias Inquiry – Fetch merchant details

Automation & Scheduling​

Custom Scheduler​

OpenConnect includes a powerful, configurable scheduler for automation:

Job Scheduling​

  • Batch processing automation
  • Reconciliation jobs
  • Cleanup and maintenance tasks
  • Reporting generation and distribution
  • Custom schedule triggers

Business Logic Execution​

Intelligent Transaction Management

Example: Timeout Transaction Recovery

  • If transactions are timing out:
    1. Scheduler automatically traces affected transactions
    2. Executes transaction inquiry on external system
    3. Retrieves actual transaction fate
    4. Updates transaction status in OpenConnect
    5. Applies remaining business logic to complete transaction
    6. Notifies relevant parties

Other Automated Workflows:

  • Batch payment processing
  • Scheduled reconciliation
  • Periodic report generation
  • Automatic compliance checks
  • System health maintenance
  • Data cleanup and archival

Benefits:

  • Reduced manual operations
  • Improved data accuracy
  • Faster issue resolution
  • Compliance automation
  • 24/7 automated processing
